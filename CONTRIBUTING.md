# Contributing to CP/M Neo

Thanks for your interest in CP/M Neo! We welcome contributions of all sizes, from documentation tweaks to hardware ports.

## Ways to Contribute
- Fix bugs and report issues
- Improve documentation and hardware setup guides
- Enhance the kernel and core system utilities
- Port CP/M Neo to new architectures or targets
- Refine the build system and tooling

## Before Making Large Changes
For significant features, kernel redesigns, or new architecture ports, please **open an issue first**. This allows us to discuss design goals and compatibility before you write code.
